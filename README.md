# AI Seminar Archive

AI 및 머신러닝 관련 세미나 발표 자료와 학습 내용을 정리한 저장소입니다.

이 레포지토리에는 각 세미나별로 다음 내용을 함께 기록합니다.

- 발표 PDF
- 세미나 핵심 개념 요약
- 주제별 학습 내용 정리
- 실제 ML/DL 학습에 연결되는 포인트

단순 자료 보관이 아니라, 세미나에서 다룬 개념을 다시 정리하고 이해한 내용을 문서화하는 것을 목표로 합니다.

## 학습 기반 확장 프로젝트

세미나에서 학습한 일부 주제는 실제 구현 프로젝트로 확장했습니다.

- **PixelLift**  
  SISR(Single Image Super-Resolution) 관련 논문 리뷰와 초해상도 모델 학습 내용을 바탕으로,  
  사전학습된 모델을 웹에서 사용할 수 있도록 구현한 프로젝트입니다.  
  Repo: [PixelLift](https://github.com/ppsssj/PixelLift)
